Week 1 recap

September 12, 2026 · Week 1

This week I learned the basics of interactive design and practiced building for the web. Interactive design is about making systems that communicate clearly with people: affordances, feedback, and progressive disclosure help users understand what they can do and what will happen next.

What I learned

  • User-centered thinking: framing tasks from the user's perspective and iterating on small prototypes.
  • Interaction patterns: buttons, links, focus/hover states, and the importance of accessible feedback.
  • Visual hierarchy: using type, spacing, and color to guide attention.
  • Practical web skills: writing HTML, styling with CSS, loading web fonts, and deploying on GitHub Pages.

Hands-on

I set up this site, experimented with typography and color, and learned about the cascade and stylesheet order. I also practiced using Git to manage files and published changes so others can view my work.
